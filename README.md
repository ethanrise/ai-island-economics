# AI时代的小岛经济学

## 当生产不再需要人，世界将如何运转

这是一本以“小岛社会”为思想实验的通俗经济学与未来社会推演作品。

我们假设有一座只有1000人的岛。最初，岛民靠捕鱼、种地、运输、制造、零售、医疗、教育和各种服务维持生活。随着AI、机器人、无人驾驶、无人机、自动工厂、智能电网和自主系统逐步进入这个社会，生产开始越来越少地依赖人的直接劳动。

故事并不从技术参数开始，而从岛上发生的一件件事情开始：第一台智能机器出现、第一批岗位消失、第一家公司实现“无人化”、全岛因停电而瘫痪、芯片突然成为稀缺品、AI模型开始决定生产效率、商品越来越便宜但居民收入却下降……

这些事件最终会把小岛推向一个核心问题：

> 当智能本身成为生产力，而生产越来越不需要人，人类几千年来建立在“劳动—收入—消费”之上的经济体系，还能否继续运行？

## 本书讨论什么

- AI如何从“工具”变成可以独立承担任务的生产力
- 能源、芯片、算力、AI和机器人如何组成新的生产链
- 自动化为何可能同时带来更高产能、更少劳动需求和新的收入问题
- 当工资的重要性下降，财富和购买力从哪里来
- UBI、全民智能资本、公共AI等制度可能如何出现
- 当稀缺从标准化商品转向土地、时间、注意力、真实体验和身份，市场会怎样变化
- 当工作不再是生存前提，人类如何重新理解职业、成功和人生意义

## 写作方法

本书借鉴《小岛经济学》的核心叙事方法，但不复制其具体内容：

> 不是先列经济学概念，再给案例；而是让小岛上的历史自然发生，让经济学问题从故事中长出来。

因此，每一章都尽量遵循这样的推进：

1. 岛上发生一件具体的事；
2. 居民作出一个看似合理的选择；
3. 这个选择带来新的后果；
4. 一个新的经济问题因此出现；
5. 问题继续推动下一章，而不是在本章被简单“讲完”。
