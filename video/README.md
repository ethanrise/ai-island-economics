# 《AI时代的小岛经济学》AI 视频制作工程

本目录用于把《AI时代的小岛经济学》的核心内容制作成一支约 12～15 分钟的完整讲解视频。

目标不是“图书宣传片”，而是用视频重新讲述整本书的核心思想实验：一座约 1000 人的小岛，在 AI、机器人与自动化逐步进入生产之后，如何经历生产率提升、劳动需求下降、收入结构变化、制度重新设计，以及“工作与生活意义”被重新定义的过程。

## 建议成片规格

- 目标时长：约 13 分钟；
- 可接受范围：12～15 分钟；
- 画幅：16:9；
- 建议分辨率：3840×2160 或 1920×1080；
- 帧率：24 fps 或 25 fps；
- 中文旁白为主；
- 字幕：简体中文，必要时保留少量英文视觉文字；
- 视觉风格：温暖、克制、轻未来感、电影化、非赛博朋克；
- 核心色彩：暖白、海水蓝、蓝灰、木色、柔和晨昏光。

## 推荐制作顺序

1. 锁定 `01-script/narration-v1.md`；
2. 依据 `02-style/` 先确定人物和场景视觉；
3. 按 `03-keyframes/keyframe-prompts.md` 生成关键帧；
4. 关键帧确认后，按 `04-video-prompts/shot-prompts.md` 做图生视频；
5. 使用 `05-audio/voice-prompt.md` 生成整条旁白；
6. 以旁白音轨为时间基准，按 `06-edit/edit-list.md` 剪辑；
7. 最后统一字幕、音效、环境声和背景音乐。

## 统一原则

- 不按 29 章逐章摘要，而是压缩成一条完整故事；
- 不把未来描绘成赛博朋克或灾难片；
- AI 与机器人是生产体系的一部分，不是视觉主角；
- 人物必须跨镜头保持年龄、外貌、服装和气质一致；
- 同一地点尽量复用同一基础设定图；
- 先图后视频，尽量避免直接纯文字生成长视频；
- 视频提示词重点描述“运动与镜头”，不要重复已经由关键帧确定的画面内容；
- 不把书中的制度选择表达成现实世界的确定预测，而保持“思想实验”语气。
